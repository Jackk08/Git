# Student Record and Academic Management System

## Objective
This project is a console-based Python application designed to manage student academic records. It was developed to demonstrate computational thinking, algorithm design, and fundamental programming concepts like loops, conditionals, and data structures.

## Features
* Add student information and subject marks
* Display all student records
* Search for specific students by Roll Number
* Calculate average marks and assign academic grades

## Files Included
* `student_system.py`: The main Python source code.
* `Project_Documentation.pdf`: Contains the problem statement, algorithms, flowcharts, pseudocode, and testing screenshots.

## How to Run
1. Ensure Python is installed on your computer.
2. Run `student_system.py` in your terminal or preferred IDE.
3. Follow the on-screen menu prompts to navigate the system.
