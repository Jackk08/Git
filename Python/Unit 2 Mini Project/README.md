# Student Record and Academic Management System
**Sanjivani University**  
**Submitted by:** Vaibhav Nanor  


## Project Objective
This project is a console-based application developed to organize, update, and retrieve academic information efficiently using Python's built-in data structures.

## Features
* Add new student records and prevent duplicates.
* Search for a student by PRN.
* Update student marks and attendance.
* Delete a student record permanently.
* Calculate average marks and identify the highest scorer.
* Filter students by department and count total enrolled students.

## Data Structures Integrated
* **Dictionaries:** Serve as the core database linking a PRN to a nested student profile.
* **Tuples:** Store immutable identity data (PRN, Registration Number, Date of Birth).
* **Lists:** Manage dynamic sequential data like marks, attendance logs, and enrolled subjects.
* **Sets:** Maintain unique university data without duplicates (Departments, Subjects).
* **Strings:** Store basic text information (Name, Address, Email).

## How to Run
1. Ensure Python 3.x is installed.
2. Open a terminal in the project directory.
3. Run the script using the command: `python student_system.py`
